How it works

  1. A real Linux machine

    Not a simulation: a complete Linux system with the same GNU tools as Ubuntu or Debian servers starts inside your browser. Nothing you type can break your computer.

  2. One idea per challenge

    Each short story teaches one new command or concept and reuses what you learned before. Hints are there when you're stuck.

  3. Instant feedback

    Press Check: the machine itself is inspected to see whether you solved it. Afterwards, an explanation shows what you learned.
